# Collaborative Coding Workflow Rules

This file outlines the rules and workflow for code modification requests in this workspace.

## Rules
1. **Analyze First**: When asked to make changes, debug, or solve a coding issue, DO NOT immediately modify code.
2. **Provide Options and Opinions**: First analyze the request and the existing codebase. Present the options, potential approaches, pros/cons, or your design opinions.
3. **Wait for Approval**: Do not edit any code files until the user explicitly approves an option or approach.
4. **No Code Blocks in Explanations**: Unless explicitly asked by the user, do not show raw code blocks in responses. Explain concepts, flows, and logic conceptually instead.
